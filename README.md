# Libreta del Gym

App web para crear tus rutinas, apuntar pesos y series, ver cómo progresas, marcar en el calendario qué rutina hiciste cada día y llevar tu peso corporal. Funciona sin conexión; los datos se guardan solo en el dispositivo (con exportar/importar copia).

https://juanmillaa.github.io/libreta-gym/
